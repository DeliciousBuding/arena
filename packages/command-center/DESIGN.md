# Arena 指挥面板 Design System（现代极简 · Achromatic）

> 本文件是前端视觉体系的唯一事实源（SSOT）。改样式前先读这里；改这里后要同步
> `public/style.css` 的 `:root` token 与组件实现。
> 设计母题：现代极简——黑/白/灰为主，彩色只用于「数据/状态/身份」三类语义；
> 阴影代替边框、留白即设计、单一白色强调；交互/排列设计（右键指挥、outliner、
> 快捷键、真实控制）是核心价值，视觉不抢戏。

## 1. 设计原则

1. **Achromatic 基调**：界面以黑/白/灰为主（`#030303`~`#fafafa`），彩色只用于
   「数据（绿=资源/成功、红=危险/敌意、橙=警告）、状态（青=tick 信号）、
   身份（租户色）」三类语义，不做装饰性渐变与光晕。
2. **阴影代替边框**：卡片层级用 `0 0 0 1px rgba(255,255,255,.02-.05)` + 柔和黑阴影
   表达抬升；实体边框只用极低透明度 `rgba(255,255,255,.06-.15)`。
3. **单一白色强调**：唯一的主行动色是纯白（primary 按钮白底黑字）；
   hover/active 走明度梯度（#fff→#e8e8e8→#d9d9d9），不引入第二种强调色。
4. **留白即设计**：面板内 padding ≥12px、卡片间距 10px、行高 1.6+；不靠边框堆砌密度。
5. **交互/排列优先**：右键指挥菜单、Outliner 分组舰队索引、快捷键指挥、
   目标模式条、真实控制链路——功能即风格；视觉保持克制不抢戏。
6. **瑞士排印**：等宽字（Geist Mono）只用于数据/标签/ID，正文用 Geist Sans；字重层次
   靠 500/600/700 三级（去掉 400 细字重），中文一律黑体类回退，杜绝细宋体。
7. **动效克制**：交互反馈 150-250ms、`cubic-bezier(.16,1,.3,1)`（expo-out）；
   `prefers-reduced-motion` 全量降级。

## 2. 颜色 token（:root）

| Token | 值 | 用途 |
|---|---|---|
| `--bg-deep` / `--bg` | `#030303` / `#060606` | 页面底 / 次级底（纯黑灰） |
| `--surface` | `rgba(16,16,16,.78)` | 面板底（+blur） |
| `--surface-solid` / `--surface-raised` | `#0e0e0e` / `rgba(23,23,23,.92)` | 实底 / 悬浮 |
| `--border` / `--border-strong` / `--border-faint` | `rgba(255,255,255,.08/.15/.05)` | 三档极淡白线（仅层级提示） |
| `--text` / `--text-dim` / `--text-faint` | `#fafafa` / `#a2a2a8` / `#6a6a70` | 三档文字（白/灰） |
| `--accent` | `#ffffff` | 单一白色强调（primary 白底黑字） |
| `--success` / `--warn` / `--danger` | `#8fce9f` / `#f0883e` / `#e0625d` | 数据/状态语义（警告=橙，非装饰黄） |
| `--green-resource` / `--cyan-signal` | `#7fc99a` / `#5fd4e8` | 资源绿 / tick 信号青 |
| `--t1..--t4` | 蓝/绿/紫/红（muted） | 租户身份（地图/小色块） |

语义色规则：白 = 强调/主行动/人类指挥最高优先；橙 = 警告/中档威胁；绿 = 资源/正向；
红 = 危险/敌意；青 = tick 信号。租户色只出现在「地图 canvas、租户名小色块、
流内租户列」——**禁止**整卡染色/左侧竖条/装饰性使用。

## 3. 字体

- 本地 `@font-face`（`public/assets/fonts/`，SIL OFL，离线可用）：
  - **Geist**（Vercel 官方）：400/500/600/700 → `--font-sans` / `--font-display`
  - **Geist Mono**：400/500/600 → `--font-mono`
- CJK 回退（**黑体类，杜绝细宋体**）：`PingFang SC` / `Microsoft YaHei UI` /
  `Microsoft YaHei` / `Noto Sans CJK SC`；Latin/数字用 Geist 保证高级感。
  `--font-mono` 末尾同样追加 CJK 黑体回退——决策流/标签等中英混排文字
  **不得**回退到 SimSun（宋体细瘦）。
- 字重体系：`--weight-regular/medium/semibold/bold`（**500/600/700/800**）；
  正文 500、数据/标签 600、标题 700——全站去掉 400 细字重，小字号也保持辨识度。
- 画布内浮动文字（`ctx.font`）：统一 `CANVAS_FONT` 粗黑体栈
  `"Geist","PingFang SC","Microsoft YaHei UI","Microsoft YaHei","Noto Sans CJK SC",sans-serif`，
  字重 600-700；**不再用 Geist Mono**（其无 CJK 字形，中文会回退成细宋体）。

## 4. 圆角 / 阴影 / 间距

| Token | 值 | 用途 |
|---|---|---|
| `--radius-sm/md/lg` | 5/8/12px | 小件 / 控件 / 卡片面板（仅 3 档） |
| `--shadow-card` | `0 0 0 1px rgba(255,255,255,.02), 0 8px 24px rgba(0,0,0,.5)` | 卡片抬升 |
| `--shadow-float` | `0 24px 64px rgba(0,0,0,.7), 0 0 0 1px rgba(255,255,255,.06)` | 悬浮层/弹窗 |
| 间距 | 4/8/12/16 节奏 | 面板 padding 12、卡片 11×13、卡片间距 10 |

## 5. 动效

| 场景 | 时长/曲线 |
|---|---|
| hover / active / 数值闪烁 | 150-250ms `--ease` |
| 面板入场 `panelIn` / `dialogIn` | 400-450ms expo-out |
| 决策流新行 `rowIn` | 500ms `--ease`，仅新行 |
| 数值变化 `valueFlash` | 700ms 白底淡出（仅值变化时打 `.flash`） |
| 折叠决策流 | height 550ms `cubic-bezier(.22,1,.36,1)` |
| 地图提示淡出 | 闲置 4.5s 后 700ms expo-out 淡出+下移；拖拽/滚轮/双击/键盘时重现 |
| tick 前进闪亮 | `tickLabel` 0.7s 白闪+微光晕（世界在走的呼吸感） |
| 决策流标签激活 | 选中态 = 白 1.5px 下划线 scaleX + 4% 浅底（`rgba(255,255,255,.05)`） |
| 回放条入场 | 进入单租户 `rbDrop` 350ms 自上滑落淡入 |
| 缩放读数反馈 | `#zoomLevel` 数值变化时 300ms `ctlPop` 弹性放大 |
| 决策行 hover | 行底 5% 白 + 租户名亮度 1.3× + 详情文字 faint→dim，200ms 过渡 |
| 租户切换过渡 | 切换单租户后 舰队HUD/索引/待执行/资源活动 重新触发 `panelIn` 丝滑重现 |
| 聚焦徽章 | 单租户时右下控件列顶部租户色胶囊 `T1 · 聚焦`（`--tc` 语义色，非装饰） |
| 回放已到最新 | 暂停在末帧时进度条转橙 + 倒计时显示「已到最新」 |
| 演练路线脉冲 | MOVE 路线有 1.8s 循环的亮色光点沿路径流动（50ms 重绘节流保证顺滑） |
| 跳图定位标记 jumpPins | 目击/扇区/事迹跳图后目标持久可见：350ms 入场 scale-in + 5s 新标记呼吸脉冲；点击 pin 或 Esc 清除（上限 12，同坐标去重刷新） |

## 6. 组件要点

- **按钮**：默认 = 极淡白线 + 5% 白底；primary = 白底黑字（现代极简主行动色），
  hover 明度梯度 #fff→#e8e8e8；ghost = 透明；active 统一 `scale(.97)`；focus-visible 白 outline。
- **租户卡**：无左侧色条；租户身份 = 名字前 8px 圆角小色块（`.tenant-name::before`）；
  solo = 租户色 40% 透明度 1px 环 + 6% 极淡底色；卡片紧凑（padding 9×12、指标 12.5px）。
- **帝国总览（顶栏资源条）**：`.empire-strip` = 每租户一数据格（`.empire-cell`，T1 蓝 / T2 绿 /
  T3 紫 / T4 红 租户色标签 + 资源值 + 工人·增量小字），hover 租户色描边提亮。
- **侧栏顺序（首屏优先）**：租户卡 → 图例 → 图层 → 租户视图 →（单租户专属）舰队HUD → 舰队索引；
  单租户专属面板放底部，避免图例/图层被挤出首屏。
- **面板**：黑灰渐变底 + blur(16) + 极淡白线（阴影代替边框）；hover 提亮边框。
  标题 = 白/灰大写等宽（`.panel-title`）。
- **标签页**：白 1.5px 下划线（scaleX 动画），激活文字纯白。
- **舰队索引（outliner）**：`.asset-row` hover 白底提亮；`.active` = 白描边 + 白底渐变
  （选中态唯一高亮）；人类指挥中单位 = 白描边 + 白底 H 徽章（`.asset-h`，黑字）。
- **地图叠层分区（互不遮挡）**：检查面板=右上、待执行命令面板=左上、资源活动=左下、
  地图控件=右下（含缩放读数 `×N` + 「全局」返回按钮，单租户时显示）、信标边缘指示自动避让控件区、
  命令窗口倒计时=顶中。
- **决策流折叠**：折叠后仍显示最新决策胶囊（`.st-live`），新行到达圆点橙提醒；
  折叠/只看决策/标签页/图层开关/决策流高度全部持久化到本机 `localStorage`（`arena-cc.prefs`），刷新恢复。
- **决策流高度拖拽**：顶部 `.stream-grip` 把手拖拽调高（140-460px，`ns-resize`），拖动期间逐帧同步画布
  位图防拉伸，松手持久化；折叠时把手隐藏、高度归 38px，展开恢复记忆高度。
- **`[hidden]` 语义兜底**：全局 `[hidden] { display: none !important; }` —— `display:flex` 等声明不得覆盖
  hidden 属性（曾致回放条 `TICK - / -` / 最新按钮在实时模式常显）。
- **租户卡 row3**：2 列 grid（`1fr 1fr`）+ `nowrap/ellipsis`，避免 5 项 flex 换行凌乱；字号 ≥10.5px。
- **三栏布局 + 可折叠侧栏（2026-08-08）**：`#layout` = flex 三列（左栏 292px / 地图 1fr / 右栏 340px）。
  左右栏共用 `SidePanel`：展开 = 内容面板，折叠 = 40px 窄条（VSCode 侧边栏模式）——窄条内竖排图标
  （左栏 = 租户色点，右栏 = 决策流/情报/兑换码 tab 图标，active 白色 2px 左竖条 `railIn` 动画）；
  宽度过渡 260ms `cubic-bezier(.22,1,.36,1)`，折叠钮悬浮栏边缘中点（hover 上浮/阴影）。折叠/展开后
  引擎 `resize()` 同步画布。折叠状态与右栏 tab 持久化（`arena-cc-web.prefs`）。
- **右栏 tab 容器（rp）**：tab 条 = 12px sans + 图标 + 白 2px 下划线 scaleX 动画（复用 .tabs 语言）；
  面板内容 `.rp-pane` 进入动画 `rpFadeUp`（240ms 上移淡入）；面板头部 = eyebrow + 15px 标题 + ghost
  刷新按钮（hover 旋转 180°）。
- **商店面板（右栏）**：eyebrow 小标题（`OFFICIAL STORE · LINUXDO`）+ 15px 主标题层级；分区
  （Cookie/账户/商品/历史）间距 10-12px；商品卡片 `shop-item`：名称 + meta 行（价格 + 库存徽章 +
  限购），hover 上浮 1px + 阴影。
- **库存徽章（`available_stock` 三档语义色）**：`库存 N` = success 描边/底色；`仅剩 ≤5` = warn（橙）；
  `缺货` = danger + 卡片 `.sold-out` 灰化（opacity .55 + 去饱和）+ 按钮禁用。徽章入场 240ms 渐入。
- **威胁情报面板（右栏）**：三 tab（威胁/信标/核心）+ 摘要 chips（`我方在榜 N` / `遭遇玩家 N`）
  + 过滤 chips（全部/我方/遭遇，过滤后无结果给明确空态文案）。行标注语义（身份，非装饰）：
  我方账号 = 白色提升行 + 白底徽章 `我们 · T1`（内含租户色小方块，`--rc` token）；遭遇玩家 =
  极淡中性底 + 描边徽章 `遭遇`（内含目击租户色圆点，hover title 显示最后目击 tick/距核心/威胁
  等级）；榜单 top3 保持 warn 色 rank。威胁 tab 默认前 30 行 + 榜外我方账号自动置顶
  （`ir-pin-sep` 分隔标注），`展开全部` 显示全量；行内 tier 标签保持精英/攻坚/常规三档胶囊。
  顶栏「威胁情报」按钮带实时 `btn-count` 徽标（/api/intel 目击唯一账号数，3s 轮询）。
- **人类指挥中标记（2026-08-08）**：舰队索引行白描边 + 白底黑字 H 徽章（`.asset-h`），
  地图受控单位画白色虚线环 + 头部 H 标签（`drawHumanMarker`）——白色 = 人类指挥最高优先语义，
  不撞 4 租户色，也不引入装饰色。
- **目标模式条（2026-08-08）**：MOVE/SHOOT/SWEEP 后动作框不消失——底部居中显示紧凑
  目标模式条（脉冲点 + 指令文本「点矿=采矿任务 · 点空地=移动任务」+ ✕ 取消按钮），
  `pointer-events:none` 穿透画布（不挡选点，仅取消按钮可点）；提交或取消后自动消失。
  解决「点了没反应」与「卡片挡住选点」两类交互问题；不可达目标 toast 反馈并保持模式。
- **右键指挥菜单（2026-08-08，Context Command Menu）**：画布 `contextmenu` = 命中
  单位/核心弹命令菜单（`.ctx-menu`：深灰底 + 白顶线 + 单位头 + 命令列），右键空白 =
  取消选中（右键空白收镜语义）。菜单项与动作面板同源（`tactActionTypes` +
  `tactAvailability`）：可用项白 hover，不可用项中性灰 blocked 带原因（点击提示 shake）；
  SELF_DESTRUCT/WAIT 不入菜单（危险/无意义动作只在动作面板）。点击菜单项复用
  `tactChooseAction`（一键提交或进入选点模式）；Esc/✕/空白关闭。
- **Outliner 分组（2026-08-08，资产列表）**：舰队索引按 核心/工人/先锋/游侠 分组
  （`.asset-group`：组头 = 折叠箭头 + 大写组名 + 白底计数徽章），组可折叠并持久化
  （`arena-cc.assetGroups`）；行内含 HP 微条（`.asset-hpbar`，低血红渐变），核心以
  hp/shield 当前最大值为基准满条。选中行 = 白描边 + 白底渐变（唯一高亮态）。
- **快捷键指挥（2026-08-08）**：选中单位后 M=移动（核心=开始迁移方向）、
  S=清扫、A=攻击、H=维修、D=回仓、C=采集、P=生产（核心聚焦生产区）、R=修复护盾；
  仅响应当前单位拥有的动作（`tactActionTypes` 判据），不可用 toast 原因；选点模式
  中不响应（防打断）。Esc 优先关右键菜单 → 取消选中 → 关信息卡 → 退单租户。
- **编队多选 + 批量命令（2026-08-08，群星式编队指挥）**：Shift 拖拽框选（白色矩形 +
  半透明填充）/ Shift 点击加选减选（toast 编队计数）；多选单位画白虚线环（主选中实环）。
  多选 ≥2 时右键任一成员弹批量命令菜单（移动/采集/回仓/维修/攻击/等待，每项显示组内
  可执行数 ×N）；批量移动/攻击走地图选点模式（整组寻路逐个提交，Shift+点击=批量入队）；
  快捷键 M/S/A/D/C/H 对编队直接生效。普通点击任一单位 = 单选（清空编队）。
- **命令队列（Orders，2026-08-08）**：MOVE 选点模式 Shift+点击目标 = 追加队列段
  （移动/采矿意图），动作面板显示队列（段列表 + 当前段高亮 + 清空按钮）；
  队列首段立即提交，遥测 satisfied（意图完成）自动推进下一段；localStorage
  （`arena-cc.queues`）持久化，刷新后继续。服务端始终单条 goal 活跃（单一 writer 不变），
  队列是前端调度层。
- **参谋建议面板（右栏，main 合入 2026-08-08）**：`STAFF ADVICE`——联盟态势/共享测绘/
  排行榜综合出的可执行运维清单（经济濒危/敌核邻近/热区逼近/抢矿冲突/高威胁玩家）。
  四档 severity 胶囊：CRITICAL=红、HIGH=橙、MEDIUM=蓝、INFO=灰；
  行 = 分类小标签（经济/军事/威胁/冲突/情报）+ 标题 + 详情 + 建议动作；30s 轮询。
- **联盟态势面板（右栏，main 合入 2026-08-08）**：`ALLIANCE SITUATION`——4 租户实时
  资源/兵力/核心状态 + 每租户 8 方向威胁扇区（敌核邻近度玫瑰）+ 敌情目击清单 +
  事迹叙事（deeds journal）。点击目击/事迹行跳转大地图定位（`jumpTo`）；15s 轮询。
- **数据管线健康芯片（顶栏，main 合入 2026-08-08）**：`health-chip` 三态胶囊——
  测绘同步（绿）/ 测绘滞后 Nt（橙）/ 测绘缺失（红，列出缺失租户），hover 显示
  最大/平均滞后 tick；/api/health/pipeline 15s 轮询。
- **事迹徽章（决策流，main 合入 2026-08-08）**：`.st-badge.deed`（橙）/ `.deed-hot`（红）
  标注事迹叙事行；`.stream-line.clickable` 决策行可点击（跳转定位/展开详情）。
- **信标轨迹独立图层（2026-08-08）**：`layers.beaconTrail` 单独控制信标历史轨迹虚线
  （原与信标精灵共用 `beacon` 开关；用户反馈「冠军之星太烦」→ 可只关轨迹留精灵）。
- **敌情记忆层（2026-08-08）**：出视野的敌方核心/战斗单位以半透明标记常驻地图——
  敌核 = 敌红菱形（s≥8 显示 username），敌单位 = 淡红圆点；透明度按 lastSeen 新鲜度衰减
  （≤300 tick 实色 → 2000 tick 极淡，>2000 敌单位不再绘制、敌核保留底线）。hover 显示
  最后目击 tick/N tick 前/威胁/距我方核心（`showMemoryTooltip`）；数据源 /api/intel
  （tenants[].enemyCores + enemyUnitMemory，30s 缓存）；独立图层「敌情记忆」+ 图例项。
- **测绘记忆 hover（2026-08-08）**：聚焦租户时测绘层（矿/障碍）可悬停查看生命周期——
  矿：状态（活跃/待确认/采过/已确认空）、见过次数（seenCount）、首次/最后看到 tick；
  障碍：最后看到 tick。命中索引由 tactSurveyLayer 构建（surveyHits），与可见格/敌情记忆
  三级优先级（可见 > 敌情记忆 > 测绘记忆）。HUD 生命行含累计阵亡数（unit_lifecycle）。
- **决策流头部结构**：`#streamToggle`（圆点+标题+计数+chevron）与 `#streamFilter`（只看决策胶囊按钮）
  是**同级兄弟**，禁止按钮嵌套按钮（非法 HTML 会导致点击拦截/冒泡异常）；折叠时隐藏过滤按钮、显示 live 胶囊。
- **只看决策过滤**：`#streamFilter` 激活（`.on`）后隐藏 `deadlineOutcome === 'not_applicable'` 的
  无需决策行（submitResult 有 accepted/not_submitted 等变体，统一按 outcome 判定），计数栏改为显示
  实际决策数；折叠态胶囊同步只显示最新实际决策，过滤后无行时胶囊隐藏（提前 return 分支也复位）。
- **键盘导航**：方向键平移 / `+` `-` 缩放（以视口中心）/ `F` 适应视口 / `G` 返回全局联盟 /
  `Esc` 取消战术选择与关闭对话框；提示栏底部同步快捷键。
- **回放战斗可视化（官方移植）**：`shotCurve`/`drawResolvedShot` 弹道弧（命中=白/琥珀、未中=灰）+
  VANGUARD `SWEEP` 剑光扇形；server 为回放事件帧补充 actor/target 坐标。
- **移动可视化（官方对齐）**：起点菱形标记 + 终点环 + 二者间虚线（`setLineDash`）+ 方向箭头，
  单位往返与算法决策 MOVE 都绘制；图层开关「计划箭头/移动轨迹」可独立关闭。
- **交互反馈层**：全局 `#uiToast` 轻提示（2.4s 自动消失）——每次点击都有反馈：
  射程内无目标/只能攻击敌方/已探索记忆·非当前 tick/不可用操作原因/已锁定目标 等。
- **不可用操作原因**：对齐官方 `unavailableReasons`——不可用操作以 amber 可点击按钮展示，
  点击 toast 显示原因（采集需站资源格/回仓需载货+己方核心/维修需核心旁/信标条件等）。
- **单位角色说明**：动作对话框底部按单位类型说明（先锋=近战清扫无法远程、游侠=远程射击、
  工人=采集回仓、核心=生产预览），杜绝"点了没反应"的困惑。
- **信标边缘指示**：位置/角度变化才重绘 DOM（防 500ms 重建吃点击）+ 事件委托 + 淡入过渡；
  ✕ 关闭并**持久化**（图层「信标指示」checkbox / T 键可恢复）· 点箭头跳到信标（保留缩放，不被 fitSolo 覆盖）；
  画布黄线与 DOM 箭头共用 `state.layers.beaconEdge` 开关，关闭后不再自动弹出。
- **聚焦退出入口（显式，杜绝"不知道怎么取消/看全局"）**：聚焦租户卡片右上角「✕ 返回全局」chip；
  再点同租户卡片、点「T1 · 聚焦 ✕」徽章、画布「← 全局联盟」按钮、`G` / `Esc`（两级：先清战术选择，再退聚焦）均可回全局。
- **性能（动画期间降级）**：视图补间/缩放阻尼期间 `LQ` 开启——静态缓存重建跳过最贵的测绘记忆层（surveySkipped），
  动画结束补一次全质量重建；动态层关 shadowBlur。避免 fitSolo/缩放时掉帧。
- **单租户进入教学**：进入聚焦 toast「点 T1·聚焦 徽章或按 G 返回全局」；聚焦徽章本身可点击返回全局。
- **重生提示**：核心被摧毁 → 非阻塞顶部紧凑卡片（图标+标题+重生 tick+反攻提示），不遮挡地图操作区。
- **地图**：画布保持官方美术素材；canvas 尺寸变化必须走 ResizeObserver 同步重设 bitmap，
  折叠/展开决策流的 550ms 过渡期间每帧同步位图（防 CSS 拉伸）。
- **威胁扇区玫瑰（2026-08-08，全局联盟）**：每己方核心按 8 方向画敌情扇区条
  （`/api/alliance/snapshot` threatSummaries，20s 节流；长度/透明度 ∝ score，租户色仅身份语义），
  <32 格显示最近距离（橙）、<18 红；随「敌情热区」图层开关显隐——大地图一眼看出
  "哪个方向敌核在逼近我方哪颗核心"。

## 7. 红线

- 不新增第三方运行时依赖（字体文件除外，属静态资源）。
- 不把租户色/语义色用于装饰（发光、渐变、大色块背景）。
- 改字体/颜色先改本文件与 `:root`，再动组件。

## 8. 真实指挥（人类最高控制权，2026-08-07）

- 意图式指挥：点工人-点移动-点目标格 = 下达持续任务。点矿格 到 mine 采矿意图（到达自动 HARVEST、
  满仓自动回仓 DEPOSIT、目标采空 satisfied 交还 agent）；点空地 到 goto 移动意图（到位即完成）。
  MOVE/SHOOT/SWEEP/SPAWN/采集/回仓/治疗等 = 一键动作（单 tick 覆盖，最高优先）。
- 交互反馈：动作按钮 title=提交（人类指挥）；动作框顶部「人类指挥已接管 N 条指令」徽章；
  提交/拒绝/意图完成均有 toast；动作框与舰队 HUD 实时回显指令状态；清除指令即交还 agent。
- 架构：前端（React /app）→ `server.ts` `/api/command*` → `data/runtime/human-commands/<tenant>.json`
  （数据层）→ `human-override.ts`（tenant 主循环提交前合并，复用 validatePlan 净校验 + 逐条拒绝原因）
  → 官方 SDK 提交（单一 writer 不变）。mode=disabled 一键交还 agent 全权。
- React 前端：`web/`（Vite+React+TS+Bun，全量 TS）。React 管 chrome（三栏布局 + 右栏面板），
  `src/engine/mapEngine.ts` 管地图/战术/回放；视觉单一源 = `public/style.css`（React 直接 import）。
  构建 `bun run build` 到 `web/dist` 到 `/app/`。
